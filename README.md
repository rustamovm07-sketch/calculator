# QaziCalculator

Offline-first Android app for recording horse processing results, reviewing history, and analyzing real SQLite records.

## Android test APK

[Download QaziCalculator for Android](downloads/QaziCalculator-debug.apk)

This is a debug-signed APK intended for device testing. To install it, download the file on your Android device, open it, and allow installation from that source if prompted. It is not a Play Store release build.
