# QaziCalculator

Offline-first Android app for recording horse processing results, reviewing history, and analyzing real SQLite records.

## Android APK

[Download QaziCalculator for Android](downloads/QaziCalculator-debug.apk)

The APK includes ARM and x86 device architectures and supports Android 5.0 (API 21) and later. Android versions older than 5.0 are not supported by the .NET MAUI runtime used by this app.

To install it, download the file on your Android device, open it, and allow installation from that source if prompted. This is a debug-signed APK intended for device testing, not a Play Store release build.
